Python Web Scraper

A Python web scraping project that extracts job listing data from Python.org website using Requests and BeautifulSoup.

Technologies Used

- Python
- Requests
- BeautifulSoup
- HTML Parsing
- pathlib

Features

- Fetch web pages using Requests.
- Parse HTML using BeautifulSoup.
- Extract job listing information.
- Scrape multiple pages using pagination.
- Create directories for storing scraped data.

Purpose

This project was developed to practice Python web scraping, HTTP requests, HTML parsing, and working with extracted web data.
